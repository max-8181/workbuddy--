# 建筑规范库项目记忆

## 项目概述
- 项目名称：ima室内规范库
- 目标：在 IMA 知识库中建立建筑规范库，支持条文级检索、状态追踪、自动更新
- 用户领域：室内设计（住宅、办公为主，后续扩展商业、酒店、餐饮）

## 已确认的设计决策
1. **分类方式**：专业领域文件夹 + 建筑类型标签（方案B），IMA 原生标签系统实现
2. **存储内容**：规范全文 PDF + 条文级摘要笔记 + 标签
3. **检索方式**：IMA 全文搜索 + AI 摘要 + 条文级摘要检索
4. **平台**：IMA 知识库（ima-mcp 连接器，已连接）
5. **初期范围**：住宅 + 办公 + 地方规定，结构可扩展

## DWG操作能力（2026-08-07 补全）
- 本机已安装 AutoCAD 2012/2014/2016/2018/2019/2020 共6个版本
- pywin32 v312 安装到 Python venv，COM连接测试通过（默认连接 AutoCAD 2016）
- 三种操作模式：
  - **Mode A（图片识别）**：JPG/PNG/PDF截图 → AI多模态看图 → 估算面积/门宽 → HTML报告
  - **Mode B（后台DWG）**：COM后台读取DWG → 精确计算 → 添加标注图层 → 存为新DWG → 发送给用户
  - **Mode C（实时AutoCAD）**：COM连接运行中的AutoCAD → 打开DWG → 实时添加标注 → 用户在CAD中可见可调
- DWG标注内容：疏散路径箭头(红)、距离标注、安全出口标记(绿圆)、疏散人数标注、合规/不合规标记、独立"消防疏散分析"图层
