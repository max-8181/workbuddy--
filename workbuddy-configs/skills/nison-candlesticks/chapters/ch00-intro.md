# 引言：蜡烛图为什么值得学

## Core Idea
交易行情图就像地图，信息越丰富，安全抵达目的地的概率越高。蜡烛图是一张比条形图更详尽、更精确的市场地图——它能显示条形图的一切信号，还多出一个分析维度。

## Frameworks Introduced
- **蜡烛图 vs 条形图的优势清单**（尼森的"双赢"论证）
  - When to use: 向任何人（包括自己）解释"为什么放弃条形图改用蜡烛图"时
  - How: 蜡烛图使用与条形图完全相同的四价数据（开、高、低、收），条形图能发出的信号它都能发出；此外它还具备四个条形图没有的能力（见 Key Takeaways）

## Key Concepts
- **多空力量消长**: 蜡烛图实体与影线形象地反映供需状况——条形图看不到这层
- **及时性优势**: 条形图形态常需数周才形成反转信号；蜡烛图常发出近期反转信号，此后 1～3 个交易时段即可能反转
- **日本交易员的影响力**: 外汇、期货、股票市场上日资每天有数十亿美元资金跟随蜡烛图信号进出——懂蜡烛图等于懂对手盘的观察方式

## Mental Models
- 把蜡烛图当作"市场的双语地图"：西方技术分析是母语，蜡烛图让你读懂日本资金的技术面视角
- Think of 蜡烛图 as 条形图的超集：一切旧信号 + 新增洞察，纯增量工具

## Anti-patterns
- **"蜡烛图会取代其他分析"**: 日本人自己的做法恰恰相反——日文技术书几乎每本都强调"必须吸收西方技术精华，在其基础上使用日本图形工具"

## Key Takeaways
1. 蜡烛图反映多空力量消长与供需状况，这是条形图做不到的
2. 蜡烛图揭示行情变动背后的力量，为分析增加一个维度
3. 反转信号更及时：信号后 1～3 个交易时段常见反转
4. 相同的四价数据 → 零信息损失，纯信息增益
5. 日本顶尖机构（人寿保险公司技术总监向管理层汇报）以蜡烛图阐述市场观点
