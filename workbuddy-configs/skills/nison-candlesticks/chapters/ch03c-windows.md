# Chapter 3c: 窗口（跳空缺口）——最强大的持续与支撑/阻力形态

## Core Idea
窗口＝跳空缺口，是威力最大的蜡烛图形态之一："反向走势遇窗口而止"。窗口是**中继形态**——出现后市场延续原趋势；同时窗口区域自动成为支撑/阻力带。核心操作原则：**收盘价封闭窗口＝原趋势宣告结束**。

## Frameworks Introduced
- **窗口基本规则**
  - When to use: 任何窗口出现后
  - How: 上升窗口＝今日低点高于昨日高点（多头持续）；下降窗口＝今日高点低于昨日低点（空头持续）。回落在上升窗口内获支撑、反弹在下降窗口内遇阻。**盘中**击穿窗口不算——必须**收盘价**封闭（周线以周五收盘为准）
- **收盘确认铁律**: 收盘价低于上升窗口底部 → 上升趋势视为完成；收盘价高于下降窗口顶部 → 多方完全胜出。宁可等收盘确认冒行情走远的风险，也不被盘中假突破欺骗
- **窗口 ＞ 阻力线（"烛光救险"，可可例）**: 阻力线被突破但上方还有未封闭的下降窗口压着 → 不进场做多；收盘未过窗口顶部，趋势仍向下
- **流星线 vs 上升窗口的冲突裁决**: 空头形态＋同向上升窗口并存时，窗口优先——想卖空须等收盘回到窗口下方
- **奔驰窗口**: 由长白实体开启的窗口＝行情朝窗口方向疾奔；后续回抽常获长白实体中点支撑
- **三时段确认**: 日本传统认为窗口在 3 个交易时段内未封闭则确认沿窗口方向运行（一说 13 个时段）。尼森的态度：3 是日本文化迷信，2/4/5 个时段未封闭同样有效——关键是多方有无能力封闭窗口
- **三窗口理论**: 连续三个同向窗口＝趋势已达极致，物极必反。操作纪律：**对冲/保护头寸可以，激进反向不行**——必须等收盘价封闭最近一个窗口才确认反转（黄金例：乌云盖顶后未封闭窗口 3，行情横盘后继续上行）
- **双黑跳空（two black gapping crows 的变体）**: 下降窗口＋随后连续两根黑实体＝"多头陷入溃败"，强空头确认
- **跳空十字星**: 下降走势中向下跳空的十字星＝卖压增强（空头），但须等确认——次日长白实体则构成启明星（转多）。上升走势中的向上跳空十字＝尼森的扩展：上升窗口部分抵消十字星的空头含义，次日续涨则市场"恢复体力"

## Key Concepts
- **窗口的三重身份**: 中继信号 ＋ 支撑/阻力带 ＋ 反转确认机制（反转信号后出现同向窗口＝确认反转，如 IBM 空头吞噬＋下降窗口）
- **快速诊断功能**: 利多消息＋创新高却守不住＋下降窗口 → 内幕者借涨出货，"收盘回不到窗口上方，下降趋势已成"（Daxro 例）
- **成交量强化**: 窗口＋巨量＝趋势背后力量充足（苹果例）

## Mental Models
- Think of 窗口 as 城墙缺口：缺口敞开着，攻方（原趋势）就守得住；收盘价是唯一能宣告缺口失守的判官
- Use 窗口叠加计数 as 情绪温度计：连续三个同向窗口＝过热，先保护、后等信号

## Anti-patterns
- **盘中封闭窗口就认输**: 只有收盘价能封闭窗口
- **见流星线就卖，无视上方开着的上升窗口**: 窗口比单根形态权重高
- **三个窗口后立刻反手**: 传统说法诱人激进，尼森明确反对——等收盘封闭最后窗口
- **跳空十字星直接当空头信号**: 下降中的跳空十字可能是启明星的前半部，必须等次日

## Worked Example
**"烛光救险"（1992 年 5 月可可，图3-50）**：3 月中旬收盘突破重要阻力线（可追溯至 1991 年 12 月）——西方技术派会视为买入信号。但 3 月上旬的下降窗口仍开着（顶部 1088 美元），收盘始终未越过窗口顶部 → 蜡烛图交易者不进场。结果：多方无力推过窗口，行情走弱。流程：发现信号冲突 → 让窗口优先 → 等收盘裁决。

## Key Takeaways
1. 窗口＝最强中继形态：上升窗口支撑回调、下降窗口压制反弹
2. 只有收盘价封闭窗口才宣告原趋势结束（周线看周五收盘）
3. 窗口优先级高于单根反转形态和被突破的阻力线
4. 反转形态＋同向窗口＝反转确认（吞噬＋窗口组合）
5. 三个同向窗口＝趋势过热：保护头寸，但反向操作须等最后窗口被收盘封闭
6. 双黑跳空＝多头溃败确认；跳空十字星须等次日验证是否演变为启明星
7. 窗口数日不封闭（2~5 个时段均可）＝趋势持续的有效确认
