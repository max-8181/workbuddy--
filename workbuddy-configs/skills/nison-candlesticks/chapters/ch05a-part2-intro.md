# 下篇引言: 差异指数与新价图总纲（三线反转 / 砖形图 / 钥匙图）

> 本篇是第6～8章三种新价图的共同原理与使用原则。先读这一篇，再看各章画法，事半功倍。

## Core Idea
蜡烛图回答"什么时候反转"，新价图回答"现在谁占优"。三种日本图形（三线反向突破图、砖形图、钥匙图）**只在创出新高/新低时才添一根新线**，因此得名"新价图"——它们滤掉时间，只留价格变动，用来判定趋势归属与了结时机。

## Frameworks Introduced
- **拔河模型（判断优势归属）**
  - When to use: 每次需要判定多空谁掌握主动权时
  - How: "市场就像拔河，关键就是要让对手失去自己的阵地。"一旦力量均衡被打破、一方被拽离阵地，输赢立判。三种新价图就是测"绳子往哪边走"的工具
- **敏感度调节旋钮（反转值/转向值/变动单位）**
  - When to use: 为具体品种、自身风格设定图形参数时
  - How: 调高阈值 → 信号少但更可靠，代价是反转确认时行情可能已远离顶底；调低阈值 → 信号多、波动频繁，代价是新趋势刚冒头就被噪声打断。**这是主观选择**，取决于：行情波动率、标的物价格高低、交易风格、时间周期、风险偏好。作者刻意不给"最优值"，只介绍日本最流行的设定
- **收盘确认 vs 盘中抢跑（新价图的通用权衡）**
  - When to use: 每种新价图产生反转信号时
  - How: 这类图形以收盘价为依据，反转必须收盘确认——但确认时价格可能已越过预设反转值很远（反转值设 2 美元，收盘时可能已变动 4 美元，白白损失 2 美元机会）。日本交易者的折中做法：**盘中触及标准先建小仓 → 收盘确认则加仓或等回调加仓 → 收盘未确认则了结小仓**
- **趋势判定 + 蜡烛图择时（二段式配合）**
  - When to use: 短线交易者使用反应偏慢的新价图时
  - How: 用新价图判定大趋势方向，再用蜡烛图顺着该方向找具体入场点。蜡烛图很少给目标价位，而新价图的反转信号正好用来决定**何时了结**基于蜡烛图信号建立的头寸

## Key Concepts
- **日本早于西方**: 蜡烛图早于西方条形图；三线反转图、砖形图、钥匙图也早于西方点线图。有日本技术分析师亲见 **1876 年的稻米行情钥匙图**
- **流行度排序（日本）**: 钥匙图 > 三线反向突破图 > 砖形图
- **为何史料稀少**: 这三种图形比较死板，给主观阐释留下的空间小，使用者多为日本金融企业管理层，普及度低——不像蜡烛图那样外观形象、灵活
- **与蜡烛图的机制差异**: 蜡烛图每有一个新时段就画一根新线（不论是否创新高/新低）；新价图必须创新高/新低才加线。因此新价图传统上**没有时间横轴**（本书为便于讲解才加了）
- **六大优点**: ①支撑区/阻力区/密集区更明显 ②过滤次要价格变动，凸显重要行情 ③凸显总体趋势 ④压缩价格变动，提供宏观长线视角 ⑤有助于判定了结头寸的时机（新价图发反转信号可用于平仓指令，弥补蜡烛图不给目标价的短板）⑥**为只提供收盘价的市场提供技术分析手段**——共同基金、国库券收益率等都能画
- **反应偏慢**: 相比蜡烛图，这三种图反应较慢，更适合长期投资者；但短线交易者同样能受益于其趋势判定能力
- **日内分时的例外**: 书中多用日线/周线；日本部分交易者用**日内分时钥匙图**，但三线反转图与砖形图一般不用日内分时（历史证明相对不那么有效）
- **第6～8章统一结构**: 概述 → 画法（逐步教你画）→ 交易技巧（日本流行策略）→ 练习题数据 + 参考答案

## Mental Models
- Think of 新价图 as 趋势的"宏观镜头"、蜡烛图 as "微观镜头"：前者定方向、后者定时机，二者互补而非替代
- Use "果树与土壤"隐喻：本书介绍的工具是优质果树，交易者自己的思想是土壤——完美结合才结得出有效的交易观念
- 作者拒绝给出"哪种图形最好"的答案：钥匙图优于三线反转图或蜡烛图？各有各的用途。连日本技术分析师协会的专家也是"用钥匙图和其他工具判断，但跟着蜡烛图信号下单"

## Anti-patterns
- **盘中触及反转标准就满仓下单**: 反转信号必须以收盘价确认；盘中抢跑只能是小仓试探，且须预设"未确认即了结"的纪律
- **指望新价图捕捉早期反转信号**: 它们反应慢于蜡烛图，用它抓顶底会系统性滞后——抓早期反转是蜡烛图的活
- **把敏感度当成可优化的客观参数**: 不存在最优反转值，只有适配自身风格与市场波动率的选择

## Key Takeaways
1. 新价图只在创新高/新低时加线，滤掉时间，只反映价格变动
2. 核心价值：判定趋势归属 + 提供了结头寸的时机（补蜡烛图无目标价之短）
3. 只需收盘价即可绘制 → 共同基金、收益率曲线等无盘中数据的市场也能用
4. 敏感度由反转值调节，是主观选择，须匹配波动率与交易风格
5. 收盘确认与盘中机会的矛盾，日本做法是小仓试探 + 收盘确认加仓 + 未确认了结
6. 与蜡烛图二段式配合：新价图定方向，蜡烛图找入场
