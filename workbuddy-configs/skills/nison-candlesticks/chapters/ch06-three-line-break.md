# Chapter 6: 三线反向突破图（三线反转图）

## Core Idea
三线反转图是"更微妙的点线图"——只用收盘价、由市场本身（而非主观规则）判定反转：收盘突破此前三根连续白线（黑线）的极值，才画一根反向"转向线"。它专为"只抓主段行情、不找顶底"的趋势交易而生。

## Frameworks Introduced
- **三线反转图画线规则**
  - When to use: 构建或解读任何三线反转图
  - How: 全部基于**收盘价**（不看盘内高低）——①收盘创新高→画白线；创新低→画黑线；否则不画 ②此前只有 1–2 根同色线时，只需突破**前一根**的极值 ③已出现 3 根（或以上）连续同色线时，必须突破**倒数第三根线**的极值才能画反向转向线：白转黑＝跌破三根白线最低点；黑转白＝升破三根黑线最高点
- **基本交易原则**: 见白线买入、见黑线卖出。三根连续白线（黑线）＝趋势确认；三连色之后的转向线＝基础性趋势转向信号
  - 缺点：收盘确认时行情可能已走远 → 对策：盘中试探性轻仓（如盘中突破 31 美元先买一部分），收盘不确认则平掉；或等转向线后回抽再进场
- **三线反转图 × 蜡烛图分工**（尼森推荐组合）
  - When to use: 需要方向过滤器时
  - How: 三线反转图定**牛熊方向**，蜡烛图定**入场时机**。熊市（黑转向线后）：蜡烛图空头信号＝做空机会、多头信号＝平空（下降窗口后的锤子线不是买入信号）；牛市（白转向线后）：长白实体中点＝回调支撑，多头信号＝买点。转向线本身可作为蜡烛图仓位的平仓触发（替代蜡烛图缺失的目标价功能）
- **敏感度调节（N 线突破家族）**: 二线＝更敏感信号多（相当于短期均线）；三线最流行；五线/十线＝只抓大行情（相当于中长期均线）。工具选择如同选均线周期——在实践中验证
- **多重确认权衡**: 等转向线后再等一根同色新线确认——"推迟了启动，降低了利润，但出错概率降低，安全因子增长"（相当于用更长均线）
- **黑鞋—白套装—脖颈（三线反转图的形态语汇）**
  - 买入口诀："黑鞋上面有白套装，白套装上面伸出脖颈时买入"——小黑线（卖压缓解）→ 白色转向线（反转）→ 短白线（喘息＋空头未回补＋第二根白线确认）
  - 卖出口诀镜像："脖颈下黑套装，黑套装下面出现黑鞋时卖出"
- **西方技术通用性**: 趋势线、支撑/阻力、双顶（镊子顶/双烟囱）、极性转换在三线反转图上同样有效；图上的阶段峰值照样构成阻力
- **迭创新高（低）计数移植**: 三线反转图上 8–10 根连续白线＝超买、8–10 根黑线＝可能反弹（Delta 例：8 个新低后反弹）

## Key Concepts
- **转向线（reversal line）**: 打破三连色极值而画出的反向线——趋势转向的正式信号
- **基价**: 画图起点的初始价格
- **收益率图的颜色反转**: 债券收益率的三线反转图中，黑线＝收益率降＝价格涨＝**多头**信号；白线＝卖出信号
- **只抓主段哲学**: 反转信号出现晚是特性不是缺陷——不找顶底更安全

## Mental Models
- Think of 三线反转图 as 低通滤波器：滤掉所有未突破三线极值的噪音，只留下趋势级变动
- Use "三线反转图导航＋蜡烛图踩油门"分工：方向交给转向线，时机交给形态

## Anti-patterns
- **把熊市中的锤子线/十字星当买入信号**: 方向过滤器为空时，蜡烛图多头信号只用于平空
- **在黑白相间的无趋势段交易**: 连续相间的黑白线＝无趋势，等待三连色
- **忽略收益率图的黑白反转**: 债券收益率图上白线是卖出信号

## Key Takeaways
1. 只用收盘价；收盘突破三连色极值才画转向线——反转标准由市场自定
2. 基本信号：见白买、见黑卖；转向线＝趋势正式转向
3. 与蜡烛图分工：三线定方向、蜡烛定时机、转向线管平仓
4. N 线可调敏感度：二线灵敏如短均线，五线/十线迟钝如长均线
5. 等第二根同色线确认＝更安全但利润更薄（个人权衡）
6. 黑鞋/白套装/脖颈是三线反转图自己的形态语汇；西方技术（趋势线/双顶/支撑阻力）完全通用
7. 8–10 根同色线＝超买超卖，与蜡烛图迭创新高（低）同源
