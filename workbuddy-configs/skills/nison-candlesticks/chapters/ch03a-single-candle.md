# Chapter 3a: 单根蜡烛线反转形态——锤子线、吊颈线、流星线

## Core Idea
三种核心单根反转形态（锤子线/吊颈线/流星线）都有长影线＋小实体，但**同一形状是看多还是看空，完全取决于它出现之前的趋势**——"出现在下方，买入；出现在上方，卖出"（日本教科书）。

## Frameworks Introduced
- **锤子线（hammer）**
  - When to use: **大幅下跌或严重超卖之后**（两三天下跌后出现的同形蜡烛无意义）
  - How: 长下影线＋小实体位于区间上端；收盘价位于或接近高点。名称双关：市场正在"锤磨底部"＋底部坚实锤打不破
  - 交易法（尼森建议）：先少量做多试水 → 回抽验证锤子线支撑再加码；止损＝收盘价低于锤子线低点
- **吊颈线（hanging man）**
  - When to use: **上升趋势的高价位区**——与锤子线形状完全相同
  - How: 必须等待转熊确认——下一时段收盘价低于吊颈线实体。确认逻辑：吊颈线实体附近买入者全部被套，认赔盘会加剧下跌。若次日收盘高于吊颈线，则其转熊含义被化解
- **流星线（shooting star）**
  - When to use: 明确上升走势之后
  - How: 长上影线＋小实体接近区间低点——空方有能力从高位急挫，市场拒绝接受新高价。上影线若穿刺阻力位后收回，同时构成看空的**上插线**
- **弹簧线（spring）与上插线（upthrust）**——西方形态与蜡烛图结合
  - When to use: 关键支撑/阻力被短暂击穿时
  - How: 弹簧线＝价格跌破支撑后无力维持低位、弹回支撑上方（看涨，"大鳄试盘"失败）；上插线＝突破阻力后缩回（看跌）。锤子线＋弹簧线同现＝强烈信号
- **极性转换原则（polarity principle）**
  - When to use: 支撑被跌破或阻力被突破之后
  - How: 阻力↔支撑角色互换；被考验次数越多，转换越彻底。吊颈线/流星线常在极性转换位确认新阻力

## Key Concepts
- **趋势前提**: 三种形态都是反转信号——没有先前的明确趋势，就没有反转可言。横盘中的同形蜡烛不是信号
- **吊颈线的长下影线悖论**: 下影线本是买盘证据，但在高位它显示的是"一旦价格下跌，多方力量相当脆弱"
- **米饭类比（raisu/gohan）**: 日本人对同一事物用不同名字，由外围因素决定——形态含义由前期趋势决定

## Mental Models
- Think of 弹簧线为"佯攻侦察"（东方兵书胜略）：大鳄用大单击穿支撑试探防守力量，弹回＝多方韧性暴露＝空头平仓
- Use 锤子线低点 as 止损锚：反弹失败后常回踩锤子线，考验通过则底部更坚实、涨势更凌厉

## Anti-patterns
- **把横盘中的长下影线当锤子线**: 位置不对，只是普通积极信号
- **见吊颈线立即做空**: 吊颈线时段行情是上涨的（下影线＝买盘尚存），必须等次日收盘确认
- **小幅下跌后数锤子线**: 两三天下跌后的锤子形无指示作用——需要"大幅下跌或严重超卖"

## Worked Example
**原油 1990（图3-8，尼森在《华尔街日报》发表的案例）**：原油期货历史高点 32 美元（1983 年起交易）；突破后目标设 40 美元（1979 年现货阻力位）。40 美元处出现吊颈线确认头部 → 回落考验支撑 → 垂死挣扎勉强破 40 → 崩溃性下跌。要点：目标位（历史阻力）＋信号（吊颈线）＋极性转换三重验证。

## Key Takeaways
1. 锤子线＝跌势后的底部反转；吊颈线＝涨势后的顶部反转；流星线＝涨势后的顶部反转
2. 形态相同，含义由前期趋势决定——横盘中的长影线小实体不构成信号
3. 吊颈线必须等下一时段收盘低于其实体才算确认；收盘高于吊颈线则信号化解
4. 锤子线止损＝收盘破锤子线低点；回抽验证支撑是更稳健的买点
5. 弹簧线/上插线与锤子线/流星线叠加时信号增强
6. 极性转换原则：支撑跌破变阻力、阻力突破变支撑，被考验越多转换越彻底
