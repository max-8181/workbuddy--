# Chapter 1: 概述

## Core Idea
本书（Beyond Candlesticks）是《日本蜡烛图技术》的进阶篇——第一本书带你到门口，本书带你进入房子内部。核心主张：单根蜡烛图可能就是市场转向的第一个征兆（日本谚语"一叶知秋"），但形态必须放在整体技术面中评估。

## Frameworks Introduced
- **"门与房子"定位框架**（尼森给本书的明确定位）
  - When to use: 判断该从哪本书、哪个层次切入
  - How: 16 世纪日本武士言"学问是一扇门，而不是房子本身"——第一本《日本蜡烛图技术》只把你带到**门口**，本书带你**进入房子内部**，里面是新的、不寻常且有效的技术手段
- **"一叶知秋"原则（单根蜡烛的信号价值）**
  - When to use: 判断是否需要从单根蜡烛读取市场状态
  - How: 单根蜡烛（尤其长影线、十字线）本身即可携带重要信息，不必等待多蜡烛形态确认
- **形态 × 环境的二维评估框架**（尼森反复强调的警告）
  - When to use: 任何蜡烛图形态出现时
  - How: 有信号价值的蜡烛只是交易决策的一个方面；必须同时检查 ①潜在风险收益比 ②该形态在整个市场技术图形中的位置
- **下篇三种"新武器"预告**: 三线反向突破图、钥匙图、砖形图——日本流行、西方几乎无人知晓的趋势判定工具

## Key Concepts
- **备兑认购期权（covered calls）**: 书中股市"卖出"信号的可选执行方式——不必须清仓，可卖出备兑认购期权、提高止损位、或冲销部分头寸
- **蜡烛图的可融合性**: 可与任何技术分析形式结合、应用于任何市场（期货、股票、债券、外汇）
- **起源早于西方图形**: 蜡烛图是日本最流行也最古老的技术分析形式，起源早于西方的点线图与条形图；但被深藏一个多世纪，西方直到尼森第一本书才知晓
- **本书刻意不列全部形态**: 与第一本书不同，本书不罗列所有蜡烛图形态——偶尔提及的隐晦形态不知道也不妨碍理解主线
- **第 3 章的视觉化语汇**: 尼森在描述形态时提供了一套独特的视觉化画线/说法，给形态分析一个全新视角（熟手也能获得新认知）
- **写作缘起**: 林语堂言"同一本书在人生不同阶段读会有不同体会"——尼森重读旧资料、翻译新日文资料、加上实战经验，才有了本书

## Mental Models
- Use "准备充分的哈德逊湾商人"模型：交易前先在总部外扎营反思准备是否充分——第2、3章就是这段"扎营"（基础与形态体系）
- Think of 形态识别 as 必要非充分条件：识别形态是入场券，风险收益比与位置才是决策
- Think of 蜡烛图 as "藏起爪子的老鹰"：日本古话"聪明的老鹰会藏起自己的爪子"——这套技术被深藏一个多世纪。今天日本交易员每天有数十亿美元资金跟着蜡烛图信号进出，你至少要知道对手在看什么
- Use "门与房子"判断自己身处何处：只会画蜡烛、认形态＝站在门口；能把它与风险收益比、整体趋势、其他技术工具组合使用＝进了房子

## Anti-patterns
- **见树不见林**: 只盯单个蜡烛形态、无视整体趋势和市场结构——第4章整章专门纠这个错
- **把罕见形态当必修**: 本书刻意不罗列所有形态；隐晦少见的形态不知道不妨碍理解

## Key Takeaways
1. 单根蜡烛图即可携带重要市场信息，不必等形态完成
2. 任何形态必须结合风险收益比与整体技术位置评估
3. 蜡烛图与任何技术分析兼容，适用于一切有四价数据的市场
4. 股市"卖出"信号可通过备兑认购期权/提高止损/部分平仓执行
5. 本书新增三种西方未知的日本图形技术（下篇）
6. 本书是"进房子"而非"入门"——假定读者已有蜡烛图基础，或读过第一本《日本蜡烛图技术》
7. 蜡烛图起源早于西方条形图与点线图，却是被深藏一个多世纪才西传的秘传技术
