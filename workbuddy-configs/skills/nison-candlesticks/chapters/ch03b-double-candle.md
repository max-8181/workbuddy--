# Chapter 3b: 双蜡烛线形态——乌云盖顶、刺穿、吞噬、包孕

## Core Idea
双蜡烛形态通过第二根蜡烛对第一根的"切入深度"或"包裹关系"量化多空力量逆转的强度。信号强度排序（同一位置）：吞噬 > 乌云盖顶/刺穿；但**位置可以逆转排序**——重要支撑位的刺穿胜过无支撑确认的吞噬。

## Frameworks Introduced
- **乌云盖顶（dark-cloud cover）**——顶部形态
  - When to use: 上升趋势后
  - How: 第一根长白实体 → 第二根黑线高开后收于白实体**中点以下**。切入越深空头意味越强；未达中点＝未完成形态，需下一时段走弱确认。合成蜡烛显示长上影线＝卖压压过买盘
  - 股市变体：开盘只需高于前收（不必高于前高）即算成立；高于前高的变体信号更强
  - 止损/反转位：收盘价穿越乌云盖顶高点则转多
- **刺穿形态（piercing pattern）**——底部形态，乌云盖顶的镜像
  - When to use: 下降走势后的低价区
  - How: 长黑实体 → 白线低开后深度切入黑实体中点以上。第二根开盘越低、收盘切入越深，形态越理想（合成蜡烛下影线越长）。日文书的描述：多方"神风特攻队式的悲壮一搏"，空方大幅抛售后供应之路被截断
- **吞噬形态（engulfing）**——最强双蜡烛形态
  - 多头吞噬：跌势中白实体包裹黑实体；空头吞噬：涨势中黑实体包裹白实体
  - 信号强度判据：小白实体＋长黑实体（空头）＞两实体等长（后者倾向横盘——可卖空波动率）
  - 最严格定义：第二根实体连影线一起完全包裹第一根
  - 股市宽容规则：第二根开盘＝前收仍算有效吞噬（Gap 周线例）
- **最后吞噬底/顶（last engulfing bottom/top）**——位置反转型形态
  - 最后吞噬底：**下降走势中**的空头吞噬反而是底部信号；收盘上破黑实体确认
  - 最后吞噬顶：**上升走势中**的多头吞噬反而可能是顶部——日本人比喻为"双双殉情"：长白实体让你爱上市场，然后一起毁灭。次日收盘低于白线收盘＝确认
- **包孕形态（harami）**——"市场出现了裂缝"/过渡期
  - When to use: 趋势后动能衰竭的预警
  - How: 长实体在前＋小实体完全在其**实体**之内（颜色不论）。小实体位于长实体中点＝可能反转；第二根四价全在第一根实体内＝反转概率更大；第二根为十字星＝**包孕十字**，反转概率最大
  - 高价包孕（小实体贴长实体上端）→ 横盘概率大于下跌，可卖空波动率；低价包孕同理镜像
  - 中继判据：涨势中行情走到包孕形态上方＝多头中继；跌势中跌破包孕低点＝卖压延续

## Key Concepts
- **切入深度原则**: 乌云盖顶/刺穿的第二根收盘切入前实体的深度直接决定信号强度
- **50% 回落位**: 任何行情回落 50% 处应密切关注——多数技术派都盯这个点位（迪士尼周线例）
- **密集成交带**: 长期横盘区被穿破后成为阻力/支撑——套牢盘解套抛售
- **十字星＋空头吞噬组合**: 十字星后的空头吞噬尤其不祥（日经指数例）
- **贪婪/恐惧不对称**: 乌云盖顶比刺穿常见——顶部恐惧更急迫（"我要出去——立刻！马上！"），底部可以从容等待

## Mental Models
- Use 合成蜡烛线一眼判形态性质：乌云盖顶＝长上影（卖压）；刺穿＝长下影（买盘）
- Think of 吞噬 as 力量完全逆转、乌云盖顶/刺穿 as 部分逆转、包孕 as 动能暂停（裂缝）——三档力度
- 西方"钥匙反转"要求创新高，蜡烛图不需要——吞噬形态能捕捉西方工具看不见的反转（S&P 例）

## Anti-patterns
- **形态脱离位置评判**: 无支撑确认的吞噬不如重要支撑位的刺穿可靠
- **等长实体吞噬当反转**: 两实体等长的吞噬倾向横盘而非反转
- **忽略包孕的第一根长度前提**: 第一根必须是相对之前明显长的实体，否则不算包孕

## Worked Example
**可口可乐区间交易（图3-29）**：44 美元阻力（十字星＋长上影确认）＋ 40 美元支撑（多头吞噬）→ 区间框架：40 附近买、44 附近卖、止损设于多头吞噬低点下方。2 月行情按此区间运行。要点：蜡烛形态提供支撑/阻力坐标，收益风险比决定是否值得出手。

## Key Takeaways
1. 乌云盖顶/刺穿要求第二根收盘越过前实体中点，未达到则等确认
2. 吞噬包裹实体即成立（股市开盘价可等于前收）；实体悬殊才强，等长倾向横盘
3. 最后吞噬底/顶：与趋势同向的"反常吞噬"是反转信号——确认看后续收盘
4. 包孕＝动能衰竭过渡期；包孕十字最强；高价/低价包孕预示横盘（波动率交易机会）
5. 形态完成后的高点/低点自动成为止损参考与极性转换坐标
6. 蜡烛图能发出西方工具（钥匙反转）漏掉的反转信号
