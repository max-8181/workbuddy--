# Chapter 8: 钥匙图（Kagi）——以粗细和肩腰读市场

## Core Idea
钥匙图用**线条粗细（阳线/阴线）**与**肩（前高）/腰（前低）的逐级高低**传递趋势强弱：价格延续则线延伸，反向达到转向值则右移一格反转；突破前高变粗、跌破前低变细。"正如蜡烛图优于条形图，钥匙图也优于点线图"（日文专著语）。

## Frameworks Introduced
- **钥匙图画线规则**
  - When to use: 构建或解读钥匙图
  - How: 基于**收盘价**＋预设转向值——①价格沿原方向 → 钥匙线延伸 ②反向变动 ≥ 转向值 → 右移一格画反向线 ③**突破前高 → 线由细变粗（转阳）；跌破前低 → 由粗变细（转阴）**，粗细从突破价位起改变 ④两线之间的短横线＝拐点线。反向但幅度不足转向值时，粗细与方向都不变
- **百分比转向值**: 绝对值转向（如 2 美元）对不同价位的股票失配 → 改用百分比（如 3%：50 元股转向值 1.50，涨到 70 元自动调至 2.10）。日本专家常用 3%，长线者 5%；软件普及后百分比已无计算负担
- **见阳买入、见阴卖出**（基本信号）: 由阴转阳（细变粗）＝买入；由阳转阴（粗变细）＝卖出。趋势市抓主段，横盘市高买低卖（同所有趋势工具）
- **肩与腰（shoulders & waists）的逐级比较**
  - When to use: 判断市场强弱结构
  - How: 前高＝肩、前低＝腰。肩腰双双逐级抬高＝强势（多方维持节节走高循环）；双双走低＝弱势。**循环被打破的第一个信号**（某腰低于前腰/某肩低于前肩）＝动能衰减预警（Janus 基金例：S6/W6 低于前位 → S5 成为阻力）
- **多级突破（double/triple break）**: 等待突破两个前高（低）才确认信号＝二级突破；三个＝三级突破。等待越久出错越少、利润越薄——风险收益的永恒权衡（麦当劳例：S6 二级突破＋W5～W6 首次低点上移＝底部证据）
- **钥匙线中点**: 上涨后的修正未触前长钥匙线中点＝多方守住腹地（看多）；反弹无力刺穿前长线中点＝多头疲弱（看空）。钥匙线越长，中点意义越大——与蜡烛图长白实体中点完全同构（债券例：M1/M2/M3 构成支撑，M4 突破后转为阻力）
- **阴阳线长度对比**: 阳段长于阴段＝多方主导；等长＝十字星式平衡（黄金期货例）
- **双窗口形态（钥匙图特有）**
  - 双窗底：下跌中反弹的肩部高点**低于**左右两个腰部低点（腰部在肩上方形成"窗口"）——肩可多个，只要不触及腰部；与阻力位突破共振时为强转牛信号（原油例）
  - 双窗顶：镜像——两个肩部低于之间的腰部（国债例）
- **西方形态全部通用**: 趋势线（Amgen 例：反弹止于钥匙线中点连线）、镊子顶（双顶）、三佛顶/底（头肩顶/底，右佛反弹止于长线中点下方＝弱、止于中点上方＝强）、极性转换（太平洋联合例：45/50 阻力变支撑）
- **迭创新高（低）移植**: 计点肩（新高）/腰（新低），9 个新高/新低后警惕反向发力（百事例：9 新高后 43 美元双顶）；日内 5 分钟钥匙图同样适用（S&P 例：9 新低＋双窗底＋趋势线破位共振）

## Key Concepts
- **转向值**: 画反向线的最小反向幅度——钥匙图的敏感度旋钮
- **拐点线**: 连接两根反向钥匙线的短横线
- **共同基金分析**: 基金只公布收盘价（无开高低）→ 蜡烛图无法绘制，钥匙图/三线反转/砖形图成为唯一可用的图形工具（麦哲伦基金例：中点破位＋高低点循环打破＋阴线段变长，三信号共振于 1993 年底逃顶）
- **钥匙图的迟钝性**: 镊子顶确认比蜡烛图晚一个月（沃尔玛例）——不适合逃顶抓底，适合吃"肉段"

## Mental Models
- Think of 钥匙图粗细 as 趋势的"电压"：粗线＝多头供电，细线＝断电，突破前高/前低＝电流换向
- Use 肩腰循环 as 台阶计数：上台阶（肩腰齐升）健壮，第一个踏空（腰低于腰）就是摔倒预警

## Anti-patterns
- **横盘市机械跟随阴阳转换**: 会高买低卖——先判断市况或调大转向值
- **把反向但未达转向值的摆动当信号**: 幅度不足既不画线也不改变粗细
- **用钥匙图找顶底**: 信号晚是结构性的——顶底判断交给蜡烛图，钥匙图管趋势

## Worked Example
**麦哲伦基金顶部判读（图8-25，仅有收盘价的基金）**：①长钥匙线 1、2、3 后的回抽全部止于线中点上方＝强势；②高点 A–E 与低点 A′–F′ 逐级抬高＝多方占优；③转折三联：高点 F 低于前高＋低点 G′ 低于前低（循环打破）＋价格压到长线 3 中点下方且阴线段长于阳线段 → 空方接管。三个独立维度（中点、肩腰循环、阴阳长度）共振确认 1993 年底顶部。

## Key Takeaways
1. 画线三要素：转向值决定反转、突破前高前低决定粗细、拐点线连接
2. 基本信号：见阳（粗）买入、见阴（细）卖出
3. 肩腰逐级高低＝强弱结构图；循环首次打破＝最早的动能预警
4. 中点：长钥匙线的中点是修正的试金石，与蜡烛图长白实体中点同构
5. 多级突破＝确认与利润的交换；二级突破信号显著增强
6. 双窗底/顶是钥匙图独有的反转形态；所有西方技术（趋势线、头肩、极性转换）通用
7. 只有收盘价的市场（共同基金）靠钥匙图三兄弟做技术分析
