# Chapter 3d: 三根以上形态与迭创新高（低）

## Core Idea
三蜡烛形态（启明星/黄昏星家族）通过"强—疑—反向强"的三段结构确认反转；迭创新高（低）则用 8–10 根创新高（低）蜡烛线的计数捕捉趋势竭尽点——"酒田身体里的根根骨头"。

## Frameworks Introduced
- **黄昏星（evening star）**——顶部三蜡烛形态
  - When to use: 上升趋势后
  - How: ①长白实体 ②小实体/十字星（不触及前实体；十字星版本＝黄昏十字星）③黑实体深度切入第一根实体。《三猿金钱录》的表述："走势发展至极端状态时，就会出现停滞。停滞生阴"——第三根黑实体出现前只能算"僵持"，不能算转熊
  - 股市弹性：实体间可以相互触及（开盘≈前收是常态），越接近标准形态头部概率越大
- **崩盘十字星（doji breakout／abandoned baby top 变体）**: 黄昏十字星的极端版——十字星**向下跳空**到白实体下方＋再一根向下跳空黑线＝"大跌的前兆"。与跳空十字星的区别：崩盘十字星出现在**上升走势后**（顶部反转），跳空十字星出现在**下降走势中**（空头中继）
- **启明星（morning star）**——底部三蜡烛形态，黄昏星镜像
  - ①长黑实体 ②小实体/十字星（启明星十字）③白实体上插第一根实体高处。第三根收盘切入越深，合成蜡烛下影线越长，多头气势越强
  - **弃婴形态（abandoned baby）**: 启明星十字中，十字星与前后两根蜡烛线都有跳空缺口＝极罕见的大底（对应西方十字岛形底）
- **非典型形态处理三步法**（尼森致函日本技术分析师协会后的结论——"西方追求精准，东方保留弹性"）
  - When to use: 形态不标准但位置关键时
  - How: ①视同标准形态判读，但**等市场进一步确认**；②若非理想形态确认了支撑/阻力位或出现在严重超买超卖区（如 50% 回落位的短下影锤子）→ 信号价值等同于标准形态；③合成蜡烛线验证——合成结果与形态预测相符即可采信
- **迭创新高（低）（climactic / record highs-lows）**——多时段趋势竭尽计数
  - When to use: 单边行情中持续计数
  - How: 从此前反向走势的极值起算，每创一次新高（低）计 1 根，**允许中间夹 2–3 根横盘蜡烛，不允许强劲反向蜡烛**；数到 8–10 根 → 停止追势/获利了结/对冲，等反转信号出现才可反向。深度回调或有效横盘会释放超买超卖 → 计数**清零重来**
  - 计数标杆 8–10 只是参考：各市场有自己的节奏（6 根或 12 根都可能出现）

## Key Concepts
- **量度跌幅/涨幅**: 双重顶确认后，高点到颈线幅度＝下跌目标（亨氏例 40.50−5≈35.50）；迭创新低＋刺穿 → 反弹目标＝跌幅 50% 回撤位
- **黄昏星/启明星的高低点构成阻力/支撑**: 以三根蜡烛线的极值为界，收盘穿越才止损
- **信号"连续性"对比**: 两根锤子线中，属于启明星组合的那根更可信（苹果例）——形态群比单根蜡烛权重高
- **黑白分明**: 连涨段多为白实体、杀跌段多为黑实体——"就像雪和炭一样黑白分明"（Amgen 例）

## Mental Models
- Think of 三蜡烛形态 as 三幕剧：力竭（长白/黑）→ 停滞（小实体）→ 逆转（反向长实体）；第二幕单独出现只是悬念，第三幕开场才是判决
- Use 新高计数 as 弦的张力：横盘或深回调＝松弦，计数清零；弦一直紧绷到第 8–10 根，崩断（修正）概率大增

## Anti-patterns
- **黄昏星数到第二根就行动**: 长白＋小实体只是僵持，必须等第三根切入确认
- **把下降中的跳空十字星当崩盘十字星**: 位置决定性质——前者中继，后者反转
- **新高计数中途遇深回调不清零**: 超买已释放，原计数作废
- **只认标准形态**: 日本人自己警告"保留灵活性，以免挂一漏万"——非标准形态＋关键位置＝有效信号

## Key Takeaways
1. 黄昏星/启明星＝最强三蜡烛反转家族；第三根实体必须深度切入第一根
2. 弃婴形态（双侧跳空的启明星十字）极罕见但极可靠；崩盘十字星是大跌前兆
3. 非典型形态：位置＞形状——支撑/阻力位或超买超卖区的变形形态有效
4. 合成蜡烛线是非典型形态的快速验证工具
5. 迭创新高（低）8–10 根＝趋势竭尽：停止追势、保护头寸，等反向信号再行动
6. 横盘 2–3 根不断计数，深回调清零重计
7. 蜡烛图与西方技术（双重顶量度跌幅、50% 回撤）无缝融合
