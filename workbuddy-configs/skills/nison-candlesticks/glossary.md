# 术语表（glossary）

《日本蜡烛图技术新解》核心术语。格式：**术语** — 定义（出处章节）。括号内章节号见 SKILL.md 索引。

## 蜡烛图基础

- **实体（real body）** — 蜡烛图矩形部分，上下端代表开收盘价；黑实体＝收低于开，白（空心）实体＝收高于开（Ch 2）
- **上影线 / 下影线** — 实体上下的细线，端点为最高/最低价；长上影＝市场拒绝高价，长下影＝卖压蒸发/空头被压倒（Ch 2）
- **长白蜡烛线（长阳线）** — 开盘近最低、收盘近最高、实体≥近期实体 3 倍；确认支撑、突破阻力、自身构成支撑（中点至低点）（Ch 2）
- **长黑蜡烛线（长阴线）** — 开盘近最高、收盘近最低、实体≥3 倍；镜像：确认阻力、突破支撑、构成阻力（中点以上至顶端）（Ch 2）
- **纺锤线（spinning top / koma）** — 小实体蜡烛，多空拉锯、动能衰减预警；结合成交量判积聚/派发（Ch 2）
- **十字星（doji）** — 开盘价＝收盘价；市场犹豫/过渡状态；趋势越成熟、超买超卖越重，信号越强；出现后等 1–2 个时段确认（Ch 2）
- **墓碑十字星（gravestone doji）** — 开、收、最低价三价合一，形如墓碑牌位（Ch 2）
- **高浪线（high-wave）** — 上下影线均长的蜡烛＝多空对峙、市场丧失方向感（Ch 2）
- **合成蜡烛线（blended candle）** — 以形态首线开盘为开、整体最高/最低为影线端点、末线收盘为收的单蜡烛概括，用于快速判形态多空性质（Ch 2/3b）
- **积聚（accumulation）** — 低价区成交量放大而价格呆滞＝空头子弹打光，看涨（Ch 2）
- **派发（distribution）** — 高价区放量价滞＝聪明钱出货，看跌（Ch 2）

## 单根反转形态

- **锤子线（hammer）** — 大跌/超卖后：小实体居区间上端＋下影线≥实体 3 倍＋短上影＝底部反转；止损设于锤子线低点（Ch 3a）
- **吊颈线（hanging man）** — 与锤子线同形但出现在涨势后＝顶部信号，**须次日收盘低于实体确认**（Ch 3a）
- **流星线（shooting star）** — 涨势后：长上影线＋小实体贴近低点＝顶部反转（Ch 3a）
- **弹簧线（spring）** — 跌破支撑后弹回支撑上方＝多头信号；锤子线＋弹簧线同现＝强信号（Ch 3a）
- **上插线（upthrust）** — 突破阻力后缩回＝空头信号，弹簧线的镜像（Ch 3a）
- **同形异义原则** — 形态含义由前期趋势决定："出现在下方买入，出现在上方卖出"（Ch 3a）

## 双蜡烛形态

- **乌云盖顶（dark-cloud cover）** — 涨势中：长白实体→高开黑线收于白实体中点下方；切入越深越空；可构成阻力（Ch 3b）
- **刺穿形态（piercing pattern）** — 跌势中：长黑实体→低开白线深度切入黑实体中点以上＝底部信号（Ch 3b）
- **多头吞噬（bullish engulfing）** — 跌势中白实体包裹前黑实体；可构成支撑（Ch 3b）
- **空头吞噬（bearish engulfing）** — 涨势中黑实体包裹前白实体；可构成阻力；实体悬殊才强，等长倾向横盘（Ch 3b）
- **最后吞噬底（last engulfing bottom）** — 跌势中的空头吞噬反而是底部信号；收盘上破黑实体确认（Ch 3b）
- **最后吞噬顶（last engulfing top）** — 涨势中的多头吞噬反可能是顶部（"双双殉情"）；次日收盘低于白线收盘确认（Ch 3b）
- **包孕形态（harami）** — 长实体在前＋小实体完全其实体内＝动能衰竭过渡期，"市场出现了裂缝"（Ch 3b）
- **包孕十字（harami cross）** — 包孕第二根为十字星，反转概率最大的变体（Ch 3b）
- **高价包孕 / 低价包孕** — 小实体贴长实体上端/下端→倾向横盘（可卖空波动率）（Ch 3b）

## 三蜡烛及以上形态

- **黄昏星（evening star）** — 顶部：长白实体→未触及前实体的小实体→深度切入第一根实体的黑实体；"停滞生阴"（Ch 3d）
- **黄昏十字星** — 黄昏星中间为十字星的版本（Ch 3d）
- **启明星（morning star）** — 底部：长黑实体→小实体→上插第一根实体高处的长白实体（Ch 3d）
- **启明十字星** — 启明星中间为十字星的版本（Ch 3d）
- **弃婴形态（abandoned baby）** — 启明星十字的极端版：十字星与前后两线均跳空＝极罕见大底（对应西方十字岛形底）（Ch 3d）
- **崩盘十字星** — 顶部：长白实体→向下跳空十字星→再向下跳空黑实体＝"大跌的前兆"；区别于黄昏十字星（十字在白实体上方）（Ch 3d）
- **跳空十字星** — 下跌市道中向下跳空的十字星＝空头信号，但次日长白实体则演变为启明星，须确认（Ch 3c）
- **三佛顶 / 三佛底** — 日本对头肩顶/底的称谓（Ch 4/8）

## 窗口（缺口）

- **窗口（window）** — 跳空缺口＝最强中继形态："反向走势遇窗口而止"；上升窗口支撑回调、下降窗口压制反弹（Ch 3c）
- **上升窗口 / 下降窗口** — 今日低点高于昨日高点 / 今日高点低于昨日低点（Ch 3c）
- **收盘确认原则（窗口版）** — 只有收盘价封闭窗口才宣告原趋势结束；周线以周五收盘为准（Ch 3c）
- **奔驰窗口** — 由长白实体开启的窗口，行情朝窗口方向疾奔（Ch 3c）
- **三窗口理论** — 连续三个同向窗口＝趋势过热；保护头寸，反向须等收盘封闭最后窗口（Ch 3c）
- **双黑跳空** — 下降窗口后连续两根黑实体＝"多头陷入溃败"（Ch 3c）
- **支撑缺口封闭** — 上升趋势中起支撑作用的上升缺口被完全封闭＝多头止损离场的**最后一次预警**（Amgen 例）（Ch 4）

## 多时段形态

- **迭创新高（低）** — 8~10 个连续（或几乎连续）新高/新低＝过热/过冷；中间允许 2–3 根横盘，深回调清零重计；"酒田身体里的根根骨头"（Ch 3d）
- **量度跌幅 / 涨幅** — 双重顶确认后，高点至颈线幅度＝下跌目标；反弹目标常用 38%/50%/62% 回撤（Ch 3d/4）

## 西方概念（与蜡烛图结合）

- **极性转换原则（polarity）** — 旧阻力↔新支撑互换；被考验次数越多转换越彻底（Ch 3a）
- **密集成交带** — 长期横盘区被穿破后成为阻力/支撑（套牢盘效应）（Ch 3b）
- **镊子顶 / 双烟囱** — 双顶形态的日本称谓（Ch 6/8）
- **该涨不涨** — 利多出现而价格滞涨＝警惕；市场对消息的反应重于消息本身（Ch 2）
- **变动率摆动指标（ROC）** — 当日收盘价与 N 天前收盘价的比较值；涨势中应持续攀升，**价创新高而变动率未创新高＝动能背离**，可独立验证蜡烛图的顶部信号（图 2-41 戴尔）（Ch 2）
- **底部宽度原则** — 支撑区被反复测试的时间越长（如两个月未破），其后的上升平台越稳固（Ch 2）

## 移动平均指标

- **黄金交叉（golden cross）** — 短期均线上穿长期均线＝多头信号（Ch 5）
- **死亡交叉（dead cross）** — 短期均线下穿长期均线＝空头信号（Ch 5）
- **差异指数（difference index）** — (收盘−MA)÷MA×100% 的摆动指标；超买超卖判定、趋势方向、背离监测；极端值因市场而异须回测（Ch 5）
- **偏离指数（deviation index）** — 收盘÷MA×100%；与差异指数完全等价（110% ≡ +10%）（Ch 5）
- **箱体震荡** — 日本人对横盘整理的称呼；消化超买超卖的方式之一（Ch 5）

## 新价图（钥匙图/砖形图/三线反转图）

- **新价图** — 无时间轴、只反映价格突破的图形总称：三线反转图、砖形图、钥匙图（Ch 6/7/8）
- **基价（base price）** — 三种新价图的画图初始价（Ch 6/7/8）
- **反转值 / 敏感度旋钮** — 新价图通用的触发阈值统称（砖形图称变动单位、钥匙图称转向值）。调高→信号少而可靠但滞后；调低→信号多但噪声大。**设定是主观活动**，取决于波动率、价位、交易风格、时间周期与风险偏好，不存在最优值（下篇引言）
- **拔河模型** — "市场就像拔河，关键让对手失去自己的阵地"；新价图的作用是判定多空谁正被拽离阵地（下篇引言）
- **收盘确认 vs 盘中抢跑** — 新价图以收盘价为依据，反转须收盘确认，但确认时价格可能已越过阈值很远；日本折中做法：盘中先建小仓→收盘确认加仓→未确认即了结（下篇引言）
- **三线反向突破图（three-line break）** — 只用收盘价；收盘突破倒数第三根同色线极值才画转向线；见白买见黑卖（Ch 6）
- **转向线（reversal line）** — 打破三连色极值画出的反向线：黑色转向线（跌破三白线低点）/白色转向线（升破三黑线高点）（Ch 6）
- **黑鞋 / 白套装 / 脖颈** — 三线反转图语汇："黑鞋上有白套装，白套装上伸出脖颈时买入"；镜像口诀卖出（Ch 6）
- **砖形图（renko / 乃日图 / 拖曳图 / 曲折图）** — 变动达预设固定单位才加等高砖块；白砖买黑砖卖（Ch 7）
- **变动单位（砖形图）** — 每加一块砖所需的最小价格变动，决定砖块大小与图形敏感度；设定主观，取决于波动率、价位、交易风格与周期（Ch 7）
- **余额舍去（砖形图）** — 不足一个单位的价格变动不在图上体现（表 7-1 标 `<`）；但已走完的部分会计入下一块砖的触发阈值（Ch 7）
- **钥匙图（kagi / 价格区间图 / 钩型图 / 增量图 / 线状图）** — 转向值决定反向画线；突破前高线变粗（阳）、跌破前低变细（阴）（Ch 8）
- **转向值** — 钥匙图反向画线所需的最小反向幅度，可用绝对值或百分比（常用 3%/5%）（Ch 8）
- **百分比钥匙图** — 转向值设为百分比而非绝对值：3% 钥匙图下股价 50 美元→转向值 1.50 美元，涨到 70 美元→2.10 美元，**转向值随价格自动缩放**；日本人因手工计算麻烦而少用，软件普及后易用；长线者常用 5%（Ch 8）
- **拐点线** — 钥匙图中连接两根反向钥匙线的短横线（Ch 8）
- **阳线 / 阴线（钥匙图）** — 钥匙线的粗段/细段；见阳买、见阴卖（Ch 8）
- **肩（shoulder）** — 钥匙图上的前高点（Ch 8）
- **腰（waist）** — 钥匙图上的前低点；肩腰逐级高低＝强弱结构（Ch 8）
- **多级突破** — 等待突破两个/三个前高（低）再确认信号＝二级/三级突破；确认越久出错越少、利润越薄（Ch 8）
- **钥匙线中点** — 长钥匙线的中点＝修正试金石，与长白实体中点同构（Ch 8）
- **双窗口（钥匙图）** — 腰部高于其间的肩部（双窗底）或肩部低于其间的腰部（双窗顶）＝钥匙图特有反转形态（Ch 8）
- **镊子顶（钥匙图）** — 钥匙图双顶；确认晚于蜡烛图——结构性迟钝（Ch 8）

## 历史与思想

- **本间宗久** — 18 世纪酒田稻米期货传奇交易者，蜡烛图思想源头（"酒田图形"得名由来）（Ch 2）
- **空米合约** — 大名以大阪仓库未来稻米收据发行的凭证，全球最早期货市场雏形（Ch 2）
- **《黄金泉——三猿金钱录》（1755）** — 相传本间宗久所著："不见邪、不听邪、不言邪"；最早的反向理论表述；"停滞生阴"（Ch 2/3d）
- **图形演化链** — 停顿图→杆状图→条形图→锚形图→蜡烛图；条形图是"蜡烛图的雏形"（Ch 2）
- **停顿图（stopping chart）** — 收盘价连线，日本最早的图形（Ch 2）
- **杆状图（pole chart）** — 只反映高低价范围的早期图形（Ch 2）
- **锚形图（anchor chart）** — 首次直观显示开收盘关系：横线＝开盘价、箭头＝收盘价（Ch 2）
- **市场变色龙** — 预先写下"证明我错了的价位"，被收盘穿越即调整立场；比剑比喻：英语 quick 兼有"迅速"与"活着"两义（Ch 4）
- **孔子选兵** — "不带视死如归的莽汉，而带谨慎面对困难、以策略谋胜的战士"；蜡烛图只是工具箱中的一件，须与稳定连贯的交易策略结合（Ch 4）
