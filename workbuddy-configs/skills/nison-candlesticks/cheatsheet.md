# 决策速查表（cheatsheet）

## 一、形态出现时的第一反应

| 看到什么 | 先问什么 | 行动 |
|---|---|---|
| 任何反转形态 | 前期有无明确趋势？ | 无趋势→不是信号（横盘中长影线/小实体无效） |
| 锤子形蜡烛 | 出现在跌势后还是涨势后？ | 跌势后＝锤子线买入；涨势后＝吊颈线等确认 |
| 长白实体 | 在什么位置？ | 低价区＝筑底征兆；支撑反弹＝确认支撑；穿阻力＝突破；其后回抽中点＝买点 |
| 十字星 | 趋势成熟度如何？ | 急升后长白实体之上＝危险；趋势初期＝无意义；等 1–2 时段确认 |
| 窗口 | 沿什么方向开？ | 同向窗口压过反向形态——流星线＋上升窗口＝不卖，等收盘回窗口下 |

## 二、信号强度速判

- **吞噬 > 乌云盖顶/刺穿**（同位置时）；但**位置 > 形态**——阻力位的乌云盖顶胜过悬空的吞噬
- 第二根切入前实体越深，双蜡烛形态越强（中点是及格线）
- 吞噬两实体等长 → 预期横盘，别当反转做
- 十字星后的空头吞噬 ＝ 加重信号
- 多信号共振（形态＋指标＋位置）＝ 高置信度决策点

## 三、止损坐标（形态自带）

| 形态/工具 | 止损位 |
|---|---|
| 锤子线做多 | 收盘低于锤子线低点 |
| 吊颈线做空 | 吊颈线实体上方（收盘确认后） |
| 乌云盖顶/吞噬做空 | 形态高点（上影线顶）上方 |
| 启明星做多 | 启明星最低点下方 |
| 上升窗口做多 | 收盘低于窗口底部 |
| 长白实体支撑买入 | 收盘低于下影线底端 |

**铁律：所有击穿以收盘价确认（周线看周五）；盘中击穿收盘拉回＝支撑仍有效。**

## 四、目标位设定（蜡烛图不提供，借西方工具）

- 前支撑/阻力位（含极性转换后）
- 趋势线与均线（52 周、200 天）
- 斐波那契回撤：38% / 50% / 62%
- 双重顶量度幅度：高点到颈线距离
- 转向线（三线反转图）作为趋势仓位的平仓触发

## 五、环境判定阈值

| 指标 | 阈值 | 注意 |
|---|---|---|
| 差异指数超买超卖 | 因市场而异（±10%~±15% 为例） | 必须自行回测 |
| 迭创新高（低） | 8–10 根（可 6~12） | 深回调清零重计 |
| 三窗口 | 连续三个同向 | 反向须等收盘封闭最后窗口 |
| 窗口三时段确认 | 2~5 个时段未封闭均有效 | "3"是日本文化迷信 |
| 200 日偏离（日经研究） | 102%–110% 为 95% 区间 | 越过 110%＝过热 |

## 六、危险信号（Tells & Smells）

- **该涨不涨**（利多＋滞涨）→ 警惕，看市场反应不看消息
- **放量纺锤线在高价区** → 派发，聪明钱出货
- **十字星/小实体集群在高位** → 多头疲惫，"行情开始背离其趋势"
- **新高蜡烛线后紧跟长上影** → 涨势停滞
- **连续 8–10 个新高** → 弦已绷紧，只等崩断
- **利多新高当日收成乌云盖顶** → 内幕者借涨出货
- **长阴长阳交错（"8 级地震"行情）** → 不交易，"无谓的牺牲"

## 七、组合工具分工

```
方向（宏观）          时机（微观）           环境
三线反转图/砖形图/钥匙图 → 蜡烛图形态信号   ← 差异指数/迭创新高计数
见白买见黑卖          锤子/吞噬/星形/窗口   超买超卖/背离
转向线管平仓          收盘确认原则          变色龙价位清单
```

**日本专家实践：用新价图和指标研判，跟蜡烛图信号下单。**

## 八、新价图选择

| 需求 | 工具 | 参数 |
|---|---|---|
| 只抓大趋势 | 砖形图 | 大砖块（低敏感） |
| 信号细腻＋形态丰富 | 钥匙图 | 3% 转向值（长线 5%） |
| 平衡（日本最流行） | 三线反转图 | 三线（短线可二线） |
| 只有收盘价的市场（共同基金） | 三种新价图均可 | — |
