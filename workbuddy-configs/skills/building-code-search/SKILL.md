# 建筑与室内设计规范检索

## 概述

本技能用于在 IMA 知识库「设计工程规范库」中检索建筑与室内设计相关规范的条文内容。支持自然语言查询，返回条文摘要、规范编号和具体条款引用。

## 知识库信息

- **知识库名称**：设计工程规范库
- **知识库 ID**：`7415660309141938`
- **收录范围**：19 部现行建筑/室内设计规范 PDF 全文（约 150MB）
- **覆盖领域**：建筑设计通用、住宅设计、办公设计、照明设计、消防安全、室内环境、无障碍设计、绿色节能、声学设计、材料施工、给排水

## 检索流程

### 第一步：分析用户查询意图

将用户的自然语言查询转化为规范检索关键词。识别以下维度：

1. **专业领域**：建筑/住宅/办公/照明/消防/环境/无障碍/节能/声学/材料/给排水
2. **建筑类型**：住宅/办公/通用
3. **查询类型**：
   - 条文查询（"XX有什么要求？"）→ 搜索具体条文
   - 规范查询（"XX规范编号是多少？"）→ 查阅规范索引
   - 参数查询（"XX的数值标准是多少？"）→ 搜索具体数值
   - 范围查询（"XX方面有哪些规范？"）→ 查阅规范索引

### 第二步：执行 IMA 知识库搜索

使用 `mcp__ima-mcp__search_knowledge` 工具搜索知识库：

```
参数：
- knowledge_base_id: "7415660309141938"
- query: <提取的关键词，使用中文>
```

搜索技巧：
- 如果用户问"住宅卧室采光要求"，搜索 query 用"住宅 卧室 采光 要求"
- 如果用户问"办公建筑疏散通道宽度"，搜索 query 用"办公建筑 疏散通道 宽度"
- 如果第一次搜索结果不够，尝试换用同义词或更宽泛的关键词再次搜索
- 对于参数类查询（如"照度标准值"），直接用参数名称搜索

### 第三步：获取详细内容（如需要）

如果搜索结果中的摘要信息不够详细，使用 `mcp__ima-mcp__fetch_media_content` 获取完整的规范条文内容：

```
参数：
- media_id: <从搜索结果获取的 media_id>
```

### 第四步：格式化返回结果

将检索结果按以下格式整理返回：

```
## 检索结果

**查询问题**：[用户的原始问题]

### 相关规范条文

**规范名称**：[规范编号] [规范名称]
**条文编号**：[具体条文号，如第X.X.X条]
**条文内容**：
[条文原文或摘要]

### 补充说明
[如有多条相关条文，依次列出]
[如涉及强制性条文，特别标注]
[如涉及废止规范替代关系，说明替代情况]
```

## 规范索引

详见 `references/code_index.md` 文件，包含全部 19 部规范的编号、名称、状态、适用范围等元数据信息。当用户询问"有哪些规范"或需要确认规范编号时，查阅此文件。

## 常见查询场景

### 场景1：条文查询
用户："住宅卧室的最小面积要求是多少？"
→ 搜索"住宅 卧室 最小面积"
→ 返回 GB 50096-2011 第5.X条相关内容

### 场景2：参数查询
用户："办公建筑走道的照度标准是多少？"
→ 搜索"办公建筑 走道 照度标准"
→ 返回 GB/T 50034-2024 相关条文

### 场景3：规范范围查询
用户："消防方面有哪些规范？"
→ 查阅 references/code_index.md
→ 列出消防安全类规范：GB 55037-2022、GB 50222-2017

### 场景4：强制性条文查询
用户："住宅设计有哪些强制性条文？"
→ 搜索"住宅设计 强制性条文"
→ 返回相关强制性条文，标注"⚠️ 强制性条文"

## 注意事项

1. **状态标注**：返回结果时注意标注规范是否为现行有效。废止规范应标注"⚫ 已废止"并说明替代规范。
2. **强制性条文**：涉及强制性条文的查询结果应特别标注"⚠️ 强制性条文，必须严格执行"。
3. **多条交叉**：同一问题可能涉及多本规范，应综合返回所有相关条文。
4. **解析状态**：部分规范 PDF 可能仍在 IMA 解析中，如搜索不到结果，告知用户该规范正在处理中。
5. **免责声明**：检索结果仅供参考，正式设计应以规范原文为准。建议用户对照 PDF 原文确认关键参数。
