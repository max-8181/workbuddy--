## 本机踩坑

- Git Bash 下 `curl -o /tmp/x.zip` 会返回 HTTP 200 但**下载 0 字节**；必须写 Windows 风格绝对路径（如工作区目录）。解压用 `python -c "zipfile..."` 最稳。
- 本机无 `gh` CLI；查 GitHub 用 `curl --noproxy '*' https://api.github.com/...`。
- book-to-skill 的依赖装在托管 venv `~/.workbuddy/binaries/python/envs/default`，用它跑才能识别到 pypdf/pdfminer/ebooklib/trafilatura 等；用裸 managed python 会全部报缺失。
- Git Bash 给 Windows python.exe 传 Y: 盘等路径必须 `cygpath -w`（否则路径解析失败）。

## 本机踩坑（补充）

- **放大看图的正确姿势**：Pillow 装不上（托管 venv pip 连不上任何索引，报 "from versions: none"）；PowerShell `Add-Type` 被安全策略阻断；`convert` 是 Windows 的 FAT 转换工具不是 ImageMagick；无 magick/ffmpeg。**可用方案：`pymupdf`（已在托管 venv）能直接打开 jpg 并 `get_pixmap(clip=..., matrix=fitz.Matrix(scale,scale))` 裁剪放大存 PNG**，读 K 图形态细节必备。
- **按图号/页码回查原书的方法**：用户常问"图X-X 在第几页"。直接用 pypdf 逐页 `extract_text()`，再 `re.sub(r'\s+','',t)` 扁平化（因该 PDF 逐字换行，不扁平化搜不到"4-11"），然后 `if '4-11' in flat` 即可定位页码，并直接输出该页全文。**比重新跑 book-to-skill 抽取快得多**（只需 1 次脚本，不用生成 cleaned.txt）。
- **已核实的页码锚点**（该 PDF，404 页）：图4-11「寻找改变市场舆论的价格」＝ PDF 第 222–223 页；图4-12（变色龙信号链）＝224 页；第4章正文自 PDF 第 186 页起；正文"引言"自 PDF 第 10 页起 → **PDF 页码 ≈ 印刷页码 + 9**（故图4-11 印刷页约 213–214）。技能 ch04 已补入原标题、页码与原句。
