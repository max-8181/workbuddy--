# GB 50016-2014 建筑设计防火规范（2018版） — 条文级摘要

> **规范编号**：GB 50016-2014（2018版局部修订）
> **规范名称**：建筑设计防火规范
> **发布日期**：2014-08-27（2018年局部修订）
> **实施日期**：2015-05-01
> **规范性质**：国标（非全文强制），强制性条文已被 GB 55037-2022 整合替代，非强制性条文仍有效
> **替代关系**：替代 GB 50016-2006；强制性条文被 GB 55037-2022 替代
> **标签**：#消防安全 #通用 #国标 #现行

---

## 重要说明

本规范的**强制性条文**已被 GB 55037-2022《建筑防火通用规范》整合替代。但第5.5章中**非强制性的计算参数表**（人员密度、百人宽度指标、疏散距离限值等）仍按本规范执行。做疏散计算时，原则性要求查 GB 55037，量化参数查本规范。

## 第5章 民用建筑

### 5.5 安全疏散

#### 5.5.15 安全出口数量

| 条件 | 安全出口数量 | 备注 |
|------|-------------|------|
| 每个防火分区 | ≥2个 | 一般规定 |
| 单层或多层首层，一二级耐火，建筑面积≤200㎡ | 可设1个 | — |
| 除托幼/老年人外，建筑面积≤50㎡且人数≤15人 | 可设1个 | — |
| 二、三层建筑（一二级耐火），每层≤200㎡且二三层人数之和≤50人 | 可设1个 | — |

#### 5.5.16 安全出口布置

- 人员密集场所的安全出口应分散布置
- 相邻两个疏散出口最近边缘之间水平距离≥5m（与 GB 55037 7.1.2 一致）

#### 5.5.17 疏散距离 — 核心计算参数

**表5.5.17 民用建筑直通疏散走道的房间疏散门至最近安全出口的直线距离(m)**

| 建筑类型 | 耐火等级 | 位于两个安全出口之间 | 位于袋形走道两侧或尽端 |
|---------|---------|-------------------|---------------------|
| 托儿所、幼儿园、老年人照料设施 | 一二级 | 25 | 20 |
| | 三级 | 20 | 15 |
| | 四级 | 15 | 10 |
| 歌舞娱乐放映游艺场所 | 一二级 | 25 | 9 |
| | 三级 | 20 | 9 |
| 医院、疗养院 | 一二级 | 35 | 20 |
| | 三级 | 30 | 15 |
| | 四级 | 25 | 10 |
| 学校 | 一二级 | 35 | 22 |
| | 三级 | 30 | 20 |
| | 四级 | 25 | 10 |
| **其他民用建筑（含办公建筑）** | **一二级** | **40** | **22** |
| | 三级 | 35 | 20 |
| | 四级 | 25 | 15 |

> **自动喷淋加成**：建筑内全部设自动喷水灭火系统时，上表疏散距离可增加25%。

#### 5.5.18 疏散门最小净宽度

| 部位 | 最小净宽度(m) | 备注 |
|------|-------------|------|
| 公共建筑疏散门/安全出口 | 0.90 | — |
| 住宅建筑户门/安全出口 | 1.10 | — |
| 人员密集公共场所/观众厅疏散门 | 1.40 | — |

#### 5.5.19 疏散走道和楼梯最小净宽度

| 部位 | 最小净宽度(m) | 备注 |
|------|-------------|------|
| 高层公共建筑疏散走道 | 1.10 | — |
| 单多层公共建筑疏散走道 | 1.00 | — |
| 住宅建筑疏散走道 | 1.10 | — |
| 高层公共建筑疏散楼梯 | 1.20 | — |
| 其他建筑疏散楼梯 | 1.10 | — |
| 住宅建筑疏散楼梯 | 1.10 | — |

#### 5.5.20 疏散人数和宽度计算 — 核心计算参数

**表5.5.20-1 厂房的百人疏散宽度指标(m/百人)**

| 厂房层数 | 百人疏散宽度指标 |
|---------|---------------|
| 一、二层 | 0.60 |
| 三层 | 0.80 |
| ≥四层 | 1.00 |

**民用建筑的百人疏散宽度指标(m/百人)**

| 建筑类型 | 楼层位置 | 百人疏散宽度指标 |
|---------|---------|---------------|
| 除厂房、商店营业厅外的民用建筑 | 一、二层 | 0.65 |
| | 三层 | 0.75 |
| | ≥四层 | 1.00 |
| 商店营业厅、展览厅 | 一、二层 | 0.65 |
| | 三层 | 0.75 |
| | ≥四层 | 1.00 |
| | 地下层 | 1.00 |

> **计算公式**：疏散总宽度 = 疏散人数 ÷ 100 × 百人疏散宽度指标

**表5.5.20-2 商店营业厅人员密度(人/㎡)**

| 楼层位置 | 人员密度 |
|---------|---------|
| 地下二层 | 0.560 |
| 地下一层 | 0.600 |
| 地上第一、二层 | 0.43~0.60 |
| 地上第三层 | 0.39~0.54 |
| 地上第四层及以上 | 0.30~0.42 |

> **办公建筑人员密度**：GB 50016 未直接规定，按实际使用人数计算，或参考 JGJ/T 67-2019《办公建筑设计标准》每人使用面积4~8㎡，即密度0.125~0.25人/㎡，典型取0.20人/㎡。

#### 5.5.21 疏散人数计算方法

| 建筑类型 | 计算方法 |
|---------|---------|
| 商店营业厅 | 建筑面积 × 表5.5.20-2人员密度 |
| 办公建筑 | 按实际使用人数（或使用面积÷4~8㎡/人） |
| 学校 | 按座位数/班额人数 |
| 医院 | 按床位数 + 每床陪护1人 |
| 体育馆/影剧院 | 按固定座位数 |
| 餐厅 | 按建筑面积 × 1.0~1.2人/㎡（参考） |
| 展览厅 | 参照商店营业厅人员密度 |

#### 5.5.27 疏散楼梯间形式

| 建筑类型 | 高度/条件 | 楼梯间形式 |
|---------|---------|---------|
| 住宅建筑 | ≤27m | 敞开楼梯间 |
| | 27m~54m | 封闭楼梯间 |
| | >54m（或>33m） | 防烟楼梯间 |
| 公共建筑 | ≤24m | 封闭楼梯间（部分可敞开） |
| | 24m~32m | 封闭楼梯间 |
| | 一类高层 或 >32m二类高层 | 防烟楼梯间 |
| 地下/半地下 | — | 防火隔墙分隔+乙级防火门 |

**防烟楼梯间前室面积要求（GB 55037 7.1.8）**

| 类型 | 最小使用面积(㎡) | 最小短边(m) |
|------|---------------|-----------|
| 公共建筑独立前室 | 6.0 | 2.4 |
| 住宅建筑独立前室 | 4.5 | 2.4 |
| 公共建筑合用前室 | 10.0 | 2.4 |
| 住宅建筑合用前室 | 6.0 | 2.4 |

## 室内设计消防疏散快速查询

### 办公建筑疏散校验清单

| 校验项 | 计算方法 | 规范限值 | 条文 |
|--------|---------|---------|------|
| 疏散人数 | 面积 × 0.20人/㎡（典型） | 按实际或参考JGJ/T 67 | 5.5.21 |
| 所需疏散总宽度 | 人数 ÷ 100 × 百人指标 | 一二层0.65、三层0.75、≥四层1.00 | 5.5.20 |
| 疏散距离（两出口间） | 平面图测量 | ≤40m（一二级耐火） | 5.5.17 |
| 疏散距离（袋形走道） | 平面图测量 | ≤22m（一二级耐火） | 5.5.17 |
| 自动喷淋加成 | 距离 × 1.25 | 设全楼自动喷淋时 | 5.5.17 |
| 安全出口数量 | — | ≥2个/防火分区 | 5.5.15 |
| 出口间距 | — | ≥5m | 5.5.16/GB55037 7.1.2 |
| 疏散门净宽 | — | ≥0.90m | 5.5.18 |
| 疏散走道净宽 | — | ≥1.10m（高层）/1.00m（单多层） | 5.5.19 |
| 疏散楼梯净宽 | — | ≥1.20m（高层）/1.10m（其他） | 5.5.19 |

### 商店营业厅疏散校验清单

| 校验项 | 计算方法 | 规范限值 | 条文 |
|--------|---------|---------|------|
| 疏散人数 | 面积 × 表5.5.20-2密度 | 地下0.56-0.60, 地上0.30-0.60 | 5.5.20-2 |
| 所需疏散总宽度 | 人数 ÷ 100 × 百人指标 | 一二层0.65、三层0.75、≥四层1.00、地下1.00 | 5.5.20-1 |
| 疏散距离（两出口间） | — | ≤40m（一二级耐火，其他民用建筑） | 5.5.17 |

## 与 GB 55037-2022 的关系

| 内容类型 | 查询规范 | 说明 |
|---------|---------|------|
| 疏散原则性要求（出口数量、间距、门开启方向等） | GB 55037-2022 | 强制性条文，优先执行 |
| 疏散量化参数（密度、宽度指标、距离限值） | GB 50016-2014(2018版) | 非强制性条文，仍有效 |
| 装修材料燃烧性能 | GB 55037 6.5章 + GB 50222 | 两者配合使用 |
| 防火分区面积 | GB 55037 4.3章 | 强制性条文 |
