# 条文摘要

## 第4章 套型设计

### 4.1 套型
- 每套住宅应设卧室、起居室（厅）、厨房和卫生间等基本空间
- 套型分类：一~四类，最小使用面积分别为 22/34/45/56㎡

### 4.8 层高、净高
- 住宅层高不应低于 2.80m
- 卧室、起居室室内净高不应低于 2.40m，局部净高不低于 2.10m
- 厨房、卫生间室内净高不应低于 2.20m

## 第5章 公共部位设计

### 5.1 楼梯（强制性条文 5.2.1）
- 楼梯梯段净宽不应小于 1.10m
- 楼梯踏步宽度不应小于 0.26m，高度不应大于 0.175m
- 6层及以下住宅，楼梯段可设1个梯段

### 5.2 电梯
- 7层及以上住宅或住户入口层楼面距室外设计地面高度超过16m时，应设电梯
- 12层及以上住宅每单元应不少于2台电梯，其中至少1台可容纳担架

## 第7章 构配件设计

### 7.1 门窗（强制性条文 7.1.4）
- 外窗窗台距楼面高度低于0.90m时，应设防护设施
- 7层及以上住宅不应采用外开平开窗
- 面向公共走道的窗扇开启不得妨碍交通

### 7.4 楼地面、屋面、墙身（强制性条文 7.4.2、7.4.3）
- 7.4.2 卫生间楼面应设防水层，防水层应沿墙面上翻不少于0.30m
- 7.4.3 厨房楼面应设防水层

## 第10章 给水排水设计（强制性条文 10.0.11）
- 10.0.11 住宅生活给水系统应设置倒流防止器

## 第12章 供配电及照明设计

### 12.1 用电负荷

**表12.1.1 用电负荷计算功率**

| 建筑面积 S（㎡） | 用电负荷计算功率（kW） |
|---|---|
| S ≤ 90 | 8 |
| 90 < S ≤ 120 | 10 |
| 120 < S ≤ 150 | 12 |
| S > 150 | 每户总建筑面积，按 80W/㎡ 计算 |

- 每套用电负荷 ≤ 12kW 时，宜单相进户；超过 12kW 或有三相电器时，应三相进户

### 12.2 供电、配电与计量

| 条文 | 核心内容 |
|---|---|
| 12.2.1 | 建筑高度 >54m：消防/安防/电梯按一级负荷供电；其他住宅：按二级负荷 |
| 12.2.2 | ≥150m 应设柴油发电机；100~150m 宜设 |
| 12.2.3 | 应急照明配电箱应由专用回路供电 |
| 12.2.5 | 住宅应分户设置电能表 |
| 12.2.8 | 供配电线路不应采用护套线明敷 |
| 12.2.9 | 单相进户铜导线 ≥10mm²；照明分支 ≥1.5mm²；插座分支 ≥2.5mm² |
| 12.2.10 | 应采用 TT 或 TN 接地形式；卫生间应做局部等电位联结；消防配电干线应采用耐火电缆；电缆应具备低烟、低毒、阻燃特性 |
| 12.2.11 | 新建住宅小区应设置电动汽车和电动自行车充电设施 |

### 12.3 电源插座（核心条文）

| 条文 | 核心内容 |
|---|---|
| 12.3.2 | 住户单元内应根据室内用电设备和家用电器配置电源插座，数量和位置应根据使用需求确定；卫生间台插座应具有防溅功能，安装位置应符合 GB 16895.13 规定 |
| 12.3.3 | 电梯坑及电梯井应设电源插座 |
| 12.3.4 | 非全装修住宅不设计插座；全装修住宅客厅、卧室、书房均应设空调设备专用插座，厨房、卫生间可设 |
| **12.3.5** | **全装修住宅电源插座的设置应满足智能家居系统功能要求。除空调插座外，全装修住宅电源插座的设置数量不应少于表12.3.5的规定** |

**表12.3.5 电源插座的最少设置数量（全装修住宅）**

| 房间名称 | 电源插座最少设置数量 |
|---|---|
| 起居室 | 单相二、三孔组合插座 **5 只** |
| 主卧室、双人卧室 | 单相二、三孔组合插座 **6 只** |
| 单人卧室 | 单相二、三孔组合插座 **4 只** |
| 书房 | 单相二、三孔组合插座 **3 只** |
| 厨房 | 单相二、三孔组合插座 **3 只** + 单相三孔带开关插座 **3 只** |
| 卫生间（有洗衣机） | 防溅型单相二、三孔组合插座 **2 只** + 防溅型单相三孔带开关插座 **2 只** |
| 卫生间（无洗衣机） | 防溅型单相二、三孔组合插座 **2 只** + 防溅型单相三孔带开关插座 **1 只** |
| 封闭式阳台 | 防溅型单相三孔带开关插座 **1 只** |

### 12.4 住户配电箱

| 条文 | 核心内容 |
|---|---|
| 12.4.1 | 每套住宅应设住户配电箱，箱内应设总断路器（短路、过载、过/欠电压保护，同时断开相线和中性线） |
| 12.4.2 | 总断路器或所有出线断路器应具有 **A型剩余电流保护功能** |
| 12.4.3 | 住户配电箱内不应设置电涌保护器 |
| 12.4.4 | 照明、空调插座、厨房插座、卫生间插座与其他插座均应 **分别设置配电回路**；柜式空调插座应单独1个回路 |

### 12.5 照明设计
- 12.5.1 公共部位照明应采用长寿命节能型灯具
- 12.5.2 公共部位一般照明应采用自熄开关控制（门厅、设备机房、消防避难层、电梯轿厢除外）

## 第13章 小区智能化及智能家居系统设计

**表13.0.7 信息插座和有线电视插座的最少设置数量**

| 房间名称 | 信息插座和有线电视插座最少设置数量 |
|---|---|
| 起居室 | 双孔信息插座 2 只，有线电视插座 1 只 |
| 卧室 | 双孔信息插座 1 只，有线电视插座 1 只 |
| 书房 | 双孔信息插座 1 只，有线电视插座 1 只 |

- 13.0.8 设智能家居系统时，应配置家庭控制器、安全防范子系统、信息网络子系统

## 第14章 供暖通风与空气调节设计
- 住宅应设置自然通风措施
- 供暖空调系统设计应符合国家和上海市现行标准

## 与国标对比要点

| 对比项 | GB 50096-2011（国标） | DGJ 08-20-2019（上海地标） |
|---|---|---|
| 用电负荷 | 每套 ≥2.5kW | 按面积分级：S≤90㎡→8kW, S>150㎡→80W/㎡ |
| 插座数量 | 卧室≥2组，起居室≥3组，厨房≥2组 | **更细化**：起居室5只、主卧6只、厨房3+3只等（表12.3.5） |
| 插座类型 | 厨房防溅水型 | 卫生间、阳台均要求防溅型，厨房要求带开关插座 |
| 全装修要求 | 未明确 | 非全装修不设计插座，全装修按表12.3.5执行 |
| 智能家居 | 无要求 | 电源插座设置应满足智能家居系统功能要求 |
| 电动汽车充电 | 无要求 | 新建小区应设充电设施 |
| 进户线截面 | ≥10mm² | 单相 ≥10mm²，三相 ≥6mm² |
| 剩余电流保护 | 未明确A型 | 明确要求 A型剩余电流保护 |

> **注意**：上海市 DGJ 08-20-2019 的电源插座要求比国标 GB 50096-2011 更严格、更细化。上海地区项目应优先执行地标。
